What it checks.

The things Android spreads across a dozen settings screens, in one place.

Permissions

Location, microphone, camera, contacts, messages, call history and photos.

Hidden access

Apps that can read your screen or notifications, or control your phone. Easy to miss, and the most powerful.

Tracker code

Known advertising and analytics code built into each app.

Forgotten apps

Apps you haven't opened in months that still have access to your data.

Questions.

Is there an iPhone version?

No. Apple doesn't let one app look at the other apps on an iPhone, so this is Android only.

Can it see what data my apps send?

No, and we won't pretend otherwise. It shows what each app is allowed to access and which known tracker code it contains, then helps you switch off what it doesn't need.

Can't Android already show me this?

Partly, spread across many settings screens and in technical language. Permwise puts it all in one list, ranks it, explains it, and adds things Android doesn't show together, like tracker code and apps you've forgotten about.

Why does it need Usage Access?

Only to see when you last opened each app, so it can find forgotten apps that still have access. It can't see what you do inside apps. You can skip it and still get the main scan.
